# Muhammad Aashir Sheraz — Portfolio

Personal portfolio. React + Vite + Tailwind CSS + Framer Motion.

## Setup

```bash
git clone <repo> && cd maashirsheraz && npm install
cp .env.example .env  # add EmailJS keys
npm run dev
```

## Deploy

```bash
npm run build && vercel --prod
```

Set `VITE_EMAILJS_*` vars in the Vercel dashboard.
